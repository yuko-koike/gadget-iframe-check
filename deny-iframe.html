iframe 拒否 確認ページ

ガジェット以外のページは X-Frame-Options: DENY / Content-Security-Policy: frame-ancestors 'none' により、iframe に表示されないことを確認するページです。
異なるオリジンのため、ブラウザはブロック結果をスクリプトに通知しません。枠が空白（または拒否アイコン）になることを目視で確認してください。

共通設定

booking.dev.ebica.jp（dev） / booking.stg.ebica.jp（stg） / booking.ebica.jp（prd）

確認対象

確認ポイント

  • 拒否対象（赤バッジ）の枠が空白のままで、予約画面が表示されない。
  • 許可対象（緑バッジ・ガジェット）の枠にはガジェットが表示される。
  • DevTools の Console に Refused to display '...' in a frame because it set 'X-Frame-Options' to 'deny'. または Refused to frame '...' because an ancestor violates the following Content Security Policy directive: "frame-ancestors 'none'". が出ている。
  • DevTools の Network でレスポンスヘッダーを見ると、拒否対象にだけ上記2ヘッダーが付いている。
